# ♟️ Шахматный тренажёр — Telegram Bot

Персональный бот для анализа партий и дебютов. Powered by Claude (Anthropic).

## Что умеет

- **Анализ партий** — скидываешь PGN, получаешь гроссмейстерский разбор
- **Разбор дебютов** — пишешь название или ходы, получаешь теорию и планы
- **Умный автодетект** — бот сам понимает что ты скинул, команды необязательны

---

## Быстрый старт

### 1. Получи токены

**Telegram бот:**
1. Напиши [@BotFather](https://t.me/BotFather) в Telegram
2. `/newbot` → придумай имя → получи токен вида `123456:ABC-DEF...`

**Свой Telegram ID:**
1. Напиши [@userinfobot](https://t.me/userinfobot)
2. Он вернёт твой числовой ID

**Anthropic API:**
1. Зайди на [console.anthropic.com](https://console.anthropic.com)
2. API Keys → Create Key

---

### 2. Деплой на Railway (рекомендуется, бесплатно)

1. Залей папку на GitHub (создай новый репо)
2. Зайди на [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. Выбери репо
4. В разделе **Variables** добавь три переменные:
   ```
   TELEGRAM_TOKEN = твой_токен_от_botfather
   ANTHROPIC_API_KEY = sk-ant-твой_ключ
   ALLOWED_USER_ID = твой_числовой_id
   ```
5. Deploy — готово, бот работает 24/7

---

### 3. Локальный запуск (для теста)

```bash
# Установи зависимости
pip install -r requirements.txt

# Создай .env файл
cp .env.example .env
# Заполни .env своими токенами

# Запусти
python bot.py
```

## Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие и инструкция |
| `/analyze` | Режим анализа партии |
| `/opening` | Режим разбора дебюта |
| `/help` | Справка |

**Без команд:** просто скинь партию или напиши название дебюта — бот сам разберётся.

---

## Примеры использования

**Анализ партии:**
```
1. d4 d5 2. c4 Nf6 3. Nf3 Bg4 4. Nc3 dxc4 5. e4 e6...
```

**Разбор дебюта:**
```
Сицилианская защита, вариант дракона
```
или
```
1. e4 c5 2. Nf3 d6 3. d4 cxd4 4. Nxd4 Nf6 5. Nc3 g6
```
